# Kulver & Preeti — Creative Studio Website

Premium 4-page website for a Photo Editing + Website Development business.
Black · Gold · White. Playfair Display + Poppins. HTML5, CSS3, vanilla JS, Bootstrap 5 & Bootstrap Icons.

## Structure
```
index.html      Home
about.html      About
projects.html   Projects / Portfolio (filterable + lightbox)
contact.html    Contact (validated form)
css/style.css   All styling (no inline CSS)
js/script.js    All interactions (no inline JS)
assets/         images / icons (see README files inside)
```

## Run
Just open `index.html` in a browser. An internet connection is used for the
Google Fonts, Bootstrap and Unsplash images (all via CDN).

## Features
- Floating glass navbar + full-screen mobile menu
- Cinematic hero with mouse parallax + draggable Before/After slider (mouse & touch)
- Services with Photo / Web tabs, 3D tilt cards, gold line animations
- Animated counters, timeline, "Why choose us", 5-step process
- Filterable portfolio with lightbox, website mockups, Before/After gallery
- Testimonials carousel (auto-advancing)
- Custom cursor (desktop), magnetic buttons, scroll-reveal, back-to-top
- Contact form with validation + success/error states (ready for backend)
- SEO meta (title, description, keywords, canonical, Open Graph, Twitter), semantic HTML, alt text, focus states, reduced-motion support
